## Environment variables

Vite uses the `FRONT_` prefix for env vars (configured in `vite.config.ts`). Required:

```
FRONT_BASE_API_URL=<url>                   # required — validated as URL by zod
FRONT_USE_LOCAL_AUTH_TOKEN=true            # optional, defaults false
FRONT_LOCAL_AUTH_TOKEN=<token>             # required when USE_LOCAL_AUTH_TOKEN=true
```

The env is parsed and validated at startup in `src/shared/lib/env.ts` using zod — the app will throw if the schema fails.

## Architecture

This is a personal finance dashboard (Russian-language UI). The app follows **Feature-Sliced Design (FSD)** layers strictly:

```
app/        Bootstrap: providers, router instance, global styles
pages/      TanStack Router file-based routes (source of truth for routing)
widgets/    Self-contained dashboard sections composed from entities/features
features/   User-facing interactions (mutations, form logic)
entities/   Domain data: API calls, query options, zod schemas
shared/     Primitives: UI components, lib utilities, types, assets
```

Import direction is one-way: `app → pages → widgets → features → entities → shared`. Never import upward.

### Routing

TanStack Router with file-based routing. Route files live in `src/pages/`. `src/routeTree.gen.ts` is auto-generated by the Vite plugin — never edit it manually. The router receives `queryClient` as context so route loaders can prefetch queries via `context.queryClient.ensureQueryData(...)`.

### Data fetching

TanStack Query. Each entity exposes:
- `*QueryOptions` — `queryOptions(...)` factories used in components and loaders
- `use*Mutation` — mutation hooks with `onSuccess` cache invalidation
- `*QueryKeys` — structured key factory

API functions live in `entity/api/*.api.ts`, query wrappers in `entity/api/*.query.ts`. Entities export only from `index.ts`.

`@/shared/api` exports reusable schemas: `objectIdSchema`, `dateStringSchema`, `entityMetaSchema`, `paginationQuerySchema`, `paginatedResponseSchema(itemSchema)`, `periodQuerySchema` (fromDate/toDate), plus `apiClient` and `parseWithSchema`.

### State

Global mutable state uses Zustand with `persist` middleware (localStorage). Currently only `src/entities/period/model/store.ts` for `selectedYear`/`selectedMonth`.

### Features

Features handle user-facing mutations and form logic. Internal structure: `model/` (Zod form schemas, `use*Mutation` hooks), `ui/` (form/dialog components), `index.ts` (exports only UI components, never model internals). Features may use entities but entities must not import from features.

### Shared UI component pattern

Components under `src/shared/ui/` use a **namespace export pattern**. Each component folder has:
- `*.tsx` — implementation, exports named parts (e.g., `CardBase`, `CardHeader`)
- `index.parts.ts` — re-exports parts under short names (`Base`, `Header`, etc.)
- `index.ts` — exports the namespace object (e.g., `export * as Card from './index.parts'`)

Usage at call sites: `<Card.Base>`, `<Button.Icon>`, `<Table.Row>`, etc.

### Entity API class pattern

Each entity has a class in `entity/api/*.api.ts` that looks like:

```ts
class XxxApi {
  private readonly client = apiClient;

  create = async (payload: CreateXxxDto) => {
    const body = createXxxPayloadSchema.parse(payload); // always validate payload first
    const response = await this.client.post<Xxx>('/xxx', body);
    return parseWithSchema(xxxSchema, response.data);   // always validate response
  };
}
export const xxxApi = new XxxApi();
```

### API client

Axios instance in `src/shared/api/client.ts`. Attaches `Authorization: Bearer <token>` from localStorage (or env var when `USE_LOCAL_AUTH_TOKEN` is set). All responses should be validated with `parseWithSchema(schema, data)` from the same file.

### Primitives: `@base-ui/react`

`@base-ui/react` is the unstyled primitive library for interactive overlays. The `Dialog` shared component (`src/shared/ui/dialog/`) wraps `Dialog` from `@base-ui/react`. For `Select` (category dropdowns, etc.), use `Select` from `@base-ui/react` directly — there is no shared wrapper. The trigger open/close state is typically managed with a local `useState` alongside `Dialog.Root`'s `onOpenChange`.

### Feature form dialog pattern

All create-* features follow the same structure in `features/*/ui/*.tsx`:

1. **Form state**: `useForm` from `@tanstack/react-form`, validated with `validators: { onSubmit: formSchema }`.
2. **Dialog**: `<Dialog.Base open={open} onOpenChange={handleOpenChange}>` + `<DialogPrimitive.Trigger>` for the `+` button.
3. **Error mapping**: A local `mapErrorMessage(code)` switch maps Zod error codes (e.g. `'required'`, `'min'`) to i18n strings via `i18next.t(...)`.
4. **Field errors**: `getFirstFieldError(field.state.meta.errors)` → `mapErrorMessage(...)` → displayed under each input.
5. **Mutation errors**: Call `createPlanMutation.reset()` on any field change (`clearMutationError()`); display `getMutationErrorMessage(mutation.error)` below the form body.
6. **On submit**: `mutateAsync(...)` → `setOpen(false)` → `formApi.reset()` → `mutation.reset()`.
7. **On close**: block if `isPending`; otherwise `setOpen(false)` + `form.reset()` + `mutation.reset()`.

### Styling

Tailwind CSS v4 (Vite plugin, not PostCSS). Custom CSS variables in `src/shared/styles/custom-vars.css`. CSS Modules supported with `camelCase` convention and hashed class names. Class merging utility: `cn()` from `@/shared/lib/shadcn-utils`.

SVGs are imported as React components via `vite-plugin-svgr`. Custom icons live in `src/shared/assets/icons/`.

Path alias: `@` maps to `src/` (configured in `vite.config.ts`).

Currency code is derived from locale via `getCurrentCurrencyCode()` in `@/shared/lib/currency` (falls back to `'RUB'`). Use this when constructing `Intl.NumberFormat` with `style: 'currency'`.

### Charts

`recharts` is used for all chart/graph widgets. Chart components live in widgets and pull pre-aggregated data from the `reports` entity query options.

### i18n

`i18next` + `react-i18next`. Russian translations in `src/shared/lib/i18n/ru/main.json`. Language detection is automatic. Translation keys are typed via `src/shared/types/i18n.d.ts`.
